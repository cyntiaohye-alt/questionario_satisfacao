# 📋 Questionário de Satisfação

## 📌 Sobre o projeto

Este projeto foi desenvolvido para realizar uma pesquisa de satisfação com clientes da empresa fictícia TudoWeb.

O programa coleta informações dos entrevistados e verifica a opinião sobre o atendimento prestado.

## 📝 Informações coletadas

O programa solicita:

- Nome do entrevistado
- Idade
- Opinião sobre o atendimento

As opções de atendimento são:

1. ⭐ Excelente
2. 👍 Bom
3. 👎 Ruim

## 📊 Resultado

Ao final da pesquisa, o programa exibe a quantidade de respostas:

- ⭐ Excelente
- 👎 Ruim

## 🔄 Estruturas utilizadas

Neste projeto foram utilizadas:

- Estrutura de repetição `for`
- Estruturas de decisão `if`
- Entrada de dados com `input()`
- Conversão de dados com `int()`
- Contadores utilizando `+= 1`

## 🧪 Testes

O programa foi testado com 50 entrevistados para verificar seu funcionamento.
